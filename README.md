# Horizon Revive (Нативный мод для Horizon Launcher)

Мод для кооперативного выживания в хардкоре для [Horizon](https://github.com/horizon-rust/horizon) (Minecraft на Rust).

Когда игрок получает смертельный урон, он **не погибает мгновенно**, а падает в состояние нокаута (Downed / Bleeding out). Если рядом есть тиммейт, он может подойти вплотную и присесть (Shift), чтобы поднять павшего товарища.

---

## 🎮 Механика

1. **Нокаут вместо смерти:**
   - При получении смертельного урона (от падения, мобов, лавы, огня, взрывов и т.д.) удар отменяется через хук `native_living_incoming_damage`.
   - Игрок падает на землю, на него накладываются эффекты: тяжелое замедление, слабость и утомление копания (чтобы он не мог убегать или драться).
   - В чат отправляется оповещение: `[Revive] <Игрок> упал! Тиммейт может поднять его, присев рядом!`.

2. **Таймер истекания кровью:**
   - По умолчанию дается **60 секунд** (1200 тиков).
   - Оставшееся время отображается в Action Bar над панелью предметов (`Bleeding out! Time left: 45s`).
   - Если по упавшему игроку наносят дополнительный урон (например, мобы продолжают бить), каждый удар **сокращает время до смерти**.
   - Если таймер истек или никто не пришел — игрок окончательно погибает (`kill`).

3. **Процесс воскрешения:**
   - Чтобы поднять товарища, живой тиммейт должен подойти ближе **2.5 блоков** и зажать **Shift (Sneak)**.
   - Пока идет воскрешение, таймер истекания кровью **приостанавливается**.
   - Обоим игрокам на экране выводится прогресс: `Reviving Alex... 45%` / `Being revived by Steve... 45%`.
   - Воскрешение занимает **5 секунд** непрерывного приседания.
   - После успешного подъема с игрока снимаются дебаффы, накладывается Регенерация и Сопротивление урону на несколько секунд, а сервер оповещает всех об успехе.

4. **Исключения:**
   - Урон от падения в Бездну (`minecraft:out_of_world`) и команда `/kill` (`minecraft:generic_kill`) не отменяются — в этих случаях спасение невозможно.
   - Если игрок остался на сервере один, смертельный урон убивает сразу (так как поднимать некому).

## 📂 Структура проекта

```text
horizon-revive/
├── Cargo.toml                    # Конфигурация для автономных тестов логики
├── compatibility.json            # Версии совместимости с Horizon и horizon-mixins
├── mixins/
│   └── revive/
│       ├── horizon-mixin.toml    # Манифест миксинов и объявления хуков
│       ├── revive_rules.rs       # Игровая логика (проверена 11 тестами)
│       ├── revive_glue.rs        # Мост с сервером Horizon (команды, эффекты, HUD)
│       ├── damage.rs             # Хук на native_living_incoming_damage
│       ├── tick.rs               # Хук на native_server_tick
│       └── lifecycle.rs          # Хук на native_world_lifecycle (сохранение состояния)
├── tools/
│   └── package.py                # Скрипт сборки готового .hnmod
└── target/
    └── revive-0.1.0.hnmod        # Готовый собранный пакет мода
```

## 🚀 Установка в Horizon Launcher

1. Поместите файл `revive-0.1.0.hnmod` (или распакованную папку) в каталог нативных модов вашей игры / инстанса:
   ```text
   <папка_игры>/horizon-native-mods/revive-0.1.0.hnmod
   ```
2. Запустите Horizon Launcher.
3. Лаунчер обнаружит нативный мод, покажет уведомление доверия и соберет Horizon с внедренным модом.
